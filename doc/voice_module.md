## 核心模块
### 口试状态机
| 属性                      | 说明                      |
| ----------------------- | ----------------------- |
| `dialogue_history`      | 对话回合记录列表，包含角色/内容/时间戳/类型 |
| `current_depth`         | 当前追问深度（0-3），防止过度追问      |
| `exam_round`            | 当前考察轮次（0-3），控制总题量       |
| `silence_thresholds`    | 静默超时阈值 `[25, 50, 75]` 秒 |
| `current_silence_level` | 当前超时等级（1-3）             |
| `waiting_for_response`  | 是否处于等待学生回答状态            |
### 三级超时
```
# 三级超时递进机制
Level 1 (25s): "同学还在吗？不用紧张..."
Level 2 (50s): "需要我提示一下，或说'下一题'跳过？"
Level 3 (75s): 根据策略执行 "结束考试" 或 "跳过本题"
```
### 口试控制
| 触发条件            | Prompt 设计目标   | 长度限制 |
| --------------- | ------------- | ---- |
| `initial`       | 基于预习答案提出探索性问题 | 100字 |
| `follow_up`     | 分析回答质量决定追问/过渡 | 100字 |
| `clarification` | 用更简单语言重述问题    | 80字  |
| `repeat`        | 清晰慢速重述（分短句）   | 80字  |
| `hint`          | 给出提示但不透露答案    | 50字  |
| `next_topic`    | 换角度提问，开启新考察点  | 100字 |
识别命令：
```python
COMMANDS = {
    "repeat": ["请重复", "再说一遍", "pardon"],
    "explain": ["什么意思", "解释一下", "什么是"],
    "hint": ["给点提示", "提示一下"],
    "skip": ["下一题", "跳过", "next"],
    "confirm": ["我答完了", "回答完毕", "done"]
}
```
### WebSocket 会话管理
```
[连接建立]
    │
    ▼
[connect()] ──► 接受连接 ──► 启动心跳(5s间隔)
    │
    ▼
[消息循环] ◄──► 处理前端指令(start_exam/audio_data/text_data/interrupt/end_exam)
    │
    ├───► 后台任务(_background_*) ──► 调用Examiner ──► 发送音频
    │
    ▼
[断开处理]
    │
    ▼
[cleanup] ──► 取消所有任务 ──► 停止超时监控 ──► 保存对话记录
```

## 超时管理
```python
时间轴 ──────────────────────────────────────────────────────►
 0s      25s          50s             75s
 │       │            │               │
 │       ▼            ▼               ▼
 │   [Level 1]    [Level 2]      [Level 3]
 │   "同学还在吗？" "需要提示吗？"  "跳过/结束"
 │       │            │               │
 │       ▼            ▼               ▼
 │   发送提醒音频  发送提示音频    执行策略:
 │   (重置计时器)  (重置计时器)    - skip: 换题
 │                               - end: 结束考试
 │
 ▼
学生说话了 ──► 调用 record_activity() ──► 重置 silence_level
```
## 错误处理
| 场景          | 处理策略                          |
| ----------- | ----------------------------- |
| TTS生成失败     | 返回 `audio_error` 消息，前端可切换文本模式 |
| WebSocket断开 | 取消所有后台任务，停止超时监控，保留已生成记录       |
| 学生频繁打断      | 每次新消息取消当前任务，立即响应最新输入          |
| LLM生成超时     | 6秒超时后重试1次，仍失败则提示"考官正在思考"      |
| 音频数据损坏      | ASR失败时返回错误，等待学生重新录音           |
