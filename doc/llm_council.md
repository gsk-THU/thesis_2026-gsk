# LLM委员会自动评分系统工作原理

## 系统概述

LLM委员会自动评分系统是一个基于多阶段大型语言模型(LLM)协作的深度理解评估框架。该系统通过模拟学术委员会的评估流程，对学生的知识理解水平进行客观、全面的评价。与传统硬编码评分规则不同，所有评价逻辑完全由LLM委员会动态生成，确保评估的灵活性和适应性。

## 核心工作流程

系统采用三阶段评估流程，结合多个LLM模型的集体智慧，最终由委员会主席做出综合裁定：

### 1. 评估启动与问题生成

当收到评估请求时，系统首先基于学生提交的原始问题和答案生成深度测试问题：
- 通过`get_questions`函数生成针对性的深度测试问题
- 每个问题分配唯一ID，形成考官问题列表
- 存储评估会话信息，包括原始问题、答案和生成的测试问题

### 2. 三阶段委员会评分流程

对每个测试问题的回答，系统执行完整的三阶段评分流程：

#### 阶段一：教师模型独立评分（stage1_teacher_scoring）
- 多个独立的教师模型对学生回答进行并行评分
- 每个模型提供独立分数和评价依据
- 系统收集所有教师模型的评分结果

#### 阶段二：同行评议（stage2_peer_review）
- 基于教师模型的评分结果，计算评分一致性（calculate_scoring_consensus）
- 分析评分分布、标准差等统计指标
- 识别异常值和潜在分歧点

#### 阶段三：主席最终裁定（stage3_chairman_final_grade）
- 委员会主席模型（CHAIRMAN_MODEL）综合所有评分信息
- 生成最终分数、等级和详细评语
- 评估并确定该问题评分的置信度

### 3. 综合评估生成

完成所有问题评分后，主席模型进行整体评估：
- 汇总各问题的评分结果和统计数据
- 分析学生在不同知识点上的表现
- 生成整体理解程度判定、知识漏洞识别和学习建议
- 计算并给出整体评估的置信度

## 置信度评估机制

置信度是LLM委员会系统的核心指标，反映了评分结果的可靠性和确定性。系统从两个层面评估置信度：

### 1. 问题级置信度

每个测试问题的评分结果都包含一个置信度指标（高/中/低），主要基于以下因素：

- **评分一致性**：教师模型之间的评分差异程度
  ```python
  # 一致性统计在metadata的consensus_stats中
  consensus_stats=metadata.get("consensus_stats", {})
  ```

- **回答质量**：学生回答的完整性、相关性和准确性
- **问题难度**：问题本身的复杂度和模糊度
- **模型确定性**：LLM在生成评分时的自我置信表达

### 2. 整体评估置信度

整体评估的置信度是一个0-1之间的浮点数，综合考虑以下因素：

- **问题间一致性**：不同测试问题评分结果的整体一致性
- **证据充分性**：支持评估结论的证据数量和质量
- **知识覆盖度**：测试问题对知识点的覆盖全面性
- **模型不确定性**：主席模型在生成评估时的不确定性表达

```python
# 主席综合评估中的置信度计算
assessment_prompt = f"""
4. **置信度评估**：给出你对以上评估的置信度（0-1之间的小数）。
"""
```

### 3. 置信度应用

- **低置信度处理**：当系统检测到低置信度评分时，可能会：
  - 生成额外的测试问题进行验证
  - 调用更专业的领域模型进行二次评估
  - 在最终报告中明确标注不确定性

- **高置信度特征**：通常表现为各教师模型评分高度一致，学生回答明确且完整，问题针对性强。

## 系统优势

1. **无硬编码规则**：所有评价逻辑由LLM动态生成，适应不同学科和问题类型
2. **多模型协作**：通过多个模型的集体智慧提高评估可靠性
3. **置信度量化**：明确的置信度指标帮助用户理解评估结果的可靠性
4. **可解释性**：提供详细的评分依据和反馈，而非简单分数
5. **自适应学习**：系统可通过反馈不断优化评估能力

LLM委员会系统代表了AI辅助教育评估的一种创新方法，通过模拟人类委员会的决策过程，结合机器学习的优势，实现更公平、客观和深入的学习评估。
