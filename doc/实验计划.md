# AI考试系统评测方案
## 评分方法
模拟真实的考试流程，使用出题LLM出三份考卷。把三份考卷的题目放在一起，使用LLM模拟三类学生完成考卷会给出的答案。
```
低水平学生：完全抄袭完成作业。
中水平学生：使用AI辅助或者借鉴别人的答案完成作业，缺少自己的理解。
高水平学生：完全自主独立思考完成作业。
```
把三份答卷提供给评分系统进行打分，统计各个LLM打分的一致性和偏差，重复多次实验，观察系统能否正确区分这三类学生。
## prompt
```
你现在模拟的是一位计算机系的学生，你的老师为了判断你的作业是否是你自己完成，给你提出了以下这些问题。
作业原题：
{}
你提交的作业：
{}
老师提出的问题：
{}
现在请模拟低水平学生（完全抄袭完成作业），中水平学生（使用AI辅助或者借鉴别人的答案完成作业，缺少自己的理解）和高水平学生（完全自主独立思考完成作业）面对这些问题给出的答案。
你的答案需要由自然语言构成，也就是学生可以口述给老师的这些答案。
```
